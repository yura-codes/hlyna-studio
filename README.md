# HLYNA

Сучасний адаптивний сайт для вигаданої керамічної студії та slow coffee bar у Чернівцях.

Проєкт створений для портфоліо та демонструє розробку інтерактивного бізнес-сайту без фреймворків: каталог майстерень, розклад, демобронювання, галерею, меню та адаптивний інтерфейс.

## Демо

**Сайт:** [yura-codes.github.io/hlyna-studio](https://yura-codes.github.io/hlyna-studio/)

## Можливості

- адаптивний дизайн для комп’ютерів, планшетів і смартфонів;
- каталог і фільтрація майстерень;
- вибір дати, часу та кількості учасників;
- перевірка форми бронювання;
- збереження демозапису в `localStorage`;
- перегляд, редагування та скасування запису;
- інтерактивна галерея;
- фільтрація меню;
- FAQ-акордеон;
- мобільна навігація;
- підтримка клавіатурного керування та `prefers-reduced-motion`.

## Запуск локально

Сторонні залежності та збірка не потрібні.

1. Завантажте або клонуйте репозиторій:

   ```bash
   git clone https://github.com/yura-codes/hlyna-studio.git
   ```

2. Перейдіть у папку проєкту:

   ```bash
   cd hlyna-studio
   ```

3. Відкрийте `index.html` у браузері.

Для коректної перевірки сайту також можна запустити локальний сервер:

```bash
python -m http.server 8000
```

Після цього відкрийте [http://localhost:8000](http://localhost:8000).

## Примітка

HLYNA — вигаданий бренд. Назва, адреса, розклад, послуги та контактні дані використовуються виключно для демонстрації проєкту в портфоліо. Бронювання на сайті є демонстраційним і не передається реальному закладу.
